# 官网首页

## Background

用户于 2026-10-21 确认：官网作为首页，现有热点列表通过“开始阅读”进入。后续聊天续接时从 `.impeccable/questions/1a43e961.answer.json` 恢复 A「热点总览」的已保存选择；用户追加首页图表改为彩色。分支 `feat/official-homepage` 基于 `origin/master` `4585021`；继续原会话工作区，原主工作区的部署文件改动保留。

## Scope

- `/`：新官网首页，解释产品、展示真实能力，引导开始阅读。
- 热点总览迁至 `/latest`，保留现有 HomeDigest、加载/失败/空状态及分区入口。
- 配套导航、首页相关链接及元数据需随职责变更核对；文章与分区 URL、RSS 地址保持稳定。
- 桌面与手机、键盘与触控布局、明暗主题。主动作默认“开始阅读”，与用户选定的首页关系一致。

## Out of scope

新增来源、Cron、数据库、翻译/总结能力扩展、登录体系及生产发布。

## Acceptance criteria

- `/` 展示已选 A 的居中标题、双入口、三个内容范围面板与来源说明，数据浏览由 `/latest` 承接。
- 彩色图表采用六个稳定分区角色；数据直接取各分区已配置来源数，附数字与文字标签，不虚构今日热度。
- 所有来源、分区、GitHub、关注、稍后读和 RSS 入口可用；文章路径及 RSS 地址不变。
- 390px、1280px、1440px 无文档级横向溢出；浅/深主题、键盘焦点和跳到内容入口可用。
- 编译、类型、测试、格式与真实浏览器检查明确记录结果和既有构建限制，不编造发布成功。

## Feasibility

现有 HomeDigest 可作为热点总览复用，不需要新依赖或数据迁移。官网可保持静态产品内容，把真实数据依赖留在内容页。切换根页面会影响“全部”、站点标志链接、离站返回路径和首页 SEO，需要按语义逐项核对。既有生产构建的路由额外导出问题记录于审计修复路线图，不能假定已解决。

## Implementation

采用 Next 16.3.4 / React 19.2.8 / Tailwind 4.3.3；沿用共享 actionStyles、ThemeToggle、SourceIcon、Lucide 及现有中文衬线标题，无新增依赖。用户后续认为主题色抽象并要求调整，用户已确认采用与火焰标识呼应的暖橙方案：浅色白底、暖深灰文字、深橙主动作；深色炭黑底、亮橙主动作。通过共享 globals.css token 同步按钮、链接、选中状态、焦点、搜索高亮、背景与边框。图表分区继续使用青、蓝、琥珀、玫红、紫、绿，保持分类意义与品牌图标。UI Skills MCP 的 interface-design 和 baseline-ui 均因传输失败未载入，采用项目内设计及 Impeccable colorize/craft-floor 指导，不声称完成 UI Skills 审查。

用户要求官网文案使用 humanizer-zh 调整，已加载该技能。最终文案集中在 [官网首页文案](official-homepage-copy.md)，视觉图依此修订，不将生成图自行添加的日期或上游订阅地址当作产品事实。

用户指出 RSS 过于突出，已调整首页层级：以多平台内容、分区浏览与文章阅读为主，稍后读及关注作为辅助体验，RSS 降为页尾补充。原 B 订阅工作台取消，改为多平台内容方案；A、C 同步去除首屏和导航里的 RSS 重点。

用户进一步明确重点应是“今日热点”。最终以“今天的热点，在这里看。”为共用主标题，首屏说明多平台热门话题与最新动态，展示热点范围、来源和分区入口。阅读工具能力退至下方，A 不再以文章阅读流程为主视觉。三个方案相应调整为热点总览、多平台热点、热点分区。之前的阅读工具及 RSS 视觉稿未获批准，不作为实施依据。

参考图来自 2026-10-20 已渲染验证的关注页深色截图，当前相关 token 未变化；当前浏览器连接超时，暂未获取新的线上截图，不将旧截图称为当前生产页面。

实现：静态首页不查询文章数据库；三组来源入口复用既有品牌图标。科技面板内的柱形图计算配置来源数，每列链接对应分区。原热点页面、测试与骨架迁至 `/latest`，视图移至 `components/latest-overview.tsx`，避免新增不合法的页面额外导出。同步“全部”导航、sitemap、内容刷新与 CDN 发布白名单，并添加 RSS 说明锚点。首页结构化数据使用 WebPage。

## Direction contract

- THESIS：让读者先看到平台覆盖与分区入口，再进入真实热点列表。首页不展示虚构新闻和排名。
- OWN-WORLD：布局与文字保留；后续主题色调整为白/炭黑底、橙色主动作、暖中性色、中文衬线大标题与细分隔线；彩色表达图表分区及品牌来源。
- STORY：理解今日热点的覆盖范围，选择开始阅读或具体来源，之后可关注、稍后读或使用 RSS。
- FIRST VIEWPORT：居中主标题和双动作，下方 AI / 科技 / 新闻社交三栏；彩色来源数量图置于科技栏，来源说明带接在三栏下方。
- FORM：A「热点总览」，保存的 optionId 为 reading-journey；已选图 `.impeccable/mocks/decision/official-homepage-overview-v3.png`。用户追加彩色图表；配置来源数替代图中没有数据意义的代码示意。移动端三栏顺序堆叠。
- FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

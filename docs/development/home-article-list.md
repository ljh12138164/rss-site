# 首页文章流与搜索高亮

## Background

用户指出首页内容空洞，提供单列新闻列表参考图，要求直接以列表或卡片展示各分区文章，并加深搜索匹配词颜色。

## Scope

修改现有首页 `/` 的页头与六分区阅读区，搜索弹窗命中标记；继续留在 `feat/section-rss-feeds`。

## Out of scope

新路由、数据库及采集修改、主题重建、图片、虚构话题标签或多来源聚合计数、部署与合并。

## Acceptance criteria

- 首页缩小介绍区，直接显示六分区的标题、摘要、时间和真实来源，不再逐来源堆叠标题、说明和数量。
- 单列文章流在桌面和手机均可读；标题自然换行、摘要两行截断，空摘要与空时间不伪造内容。
- 全部分区及来源链接保留；国内新闻优先进入本站详情，其他来源沿用外链中转。
- 空分区和读取失败有简洁真实状态；部分来源失败时仍展示可用文章并说明缺失。
- 搜索匹配词为深蓝底白字，明暗主题均达到普通文字 4.5:1 对比度。

## Feasibility

可行。首页已读取 36 个来源的首条文章，其中含摘要、作者、发布时间和持久化 ID；当前仅缺少呈现。
保持已有查询和来源顺序，不增加请求和虚假跨平台排名。只截取送入首页的长摘要展示片段，避免输出大段隐藏内容。
复用 Next 16.3.4、React 19.2.8、React Aria 1.17.0、Tailwind 4.3.3、Lucide 和现有无图风格。
Next dev 自动生成 next-env 类型路径变化已辨认为开发产物；构建时由 Next 恢复。

## Implementation

### 首页视觉细化（2026-09-06）

- 用户反馈平铺列表单调，继续在已授权首页范围内优化，保留现有分区与内容顺序。可行性不变：仅服务端呈现和 CSS，不增加请求、客户端状态或依赖。
- 采用分区目录与阅读面板：1024px 以上目录靠左吸附，小屏横向滚动；分区使用主题图标、浅底标题栏和独立内容面板。目录仍是首页锚点，和进入专区的主导航职责不同。
- 卡片底色调整为浅色 White #ffffff / 深色 Raised Navy #182235，与页面背景分层；沿用蓝色强调、无衬线文章标题和等宽日期。来源名称前用首字标识（非官方 logo），来源和时间移到标题上方，摘要统一 14px，降低连续文章的视觉重量。
- 没有采用彩虹分类或额外装饰卡片；以目录和文章阅读区的布局变化作为重点。空态、部分失败和全部失败仍保留。
- 验证：69 项 Web 测试及生产构建通过。修正旧测试直接匹配 HTML 中 `2H` 的误报（新 SVG 路径包含该字符），改为检查去标签后的文本。1280px 桌面、390px 手机的真实内容和明暗主题已截图检查；手机无横向页面溢出，分区锚点可用。
- Standards / Spec 复审：无新路由、查询或依赖，文章链接与缺失字段处理保留；面板层次、来源辨识和响应式目录覆盖此次反馈。无阻塞问题和范围外后续。

- 用户图片明确了单列文章列表、蓝色标题交互和弱化元数据；此次作为现有界面的已授权设计变更，不重复确认。
- 已读取 frontend-design；继续应用本任务已完整取得的 UI Skills interface-design 与 baseline-ui，以及 UI quality 约束。
- 读者希望快速扫读各分区内容，进入原文或分区；以文章标题为焦点，来源和时间辅助判断，取消大面积宣传式页头。
- 色彩沿用 Paper #f7f9fc、Ink #1e293b、Night #111827、Slate #64748b、Blue #2563eb；命中标记使用 Deep Blue #1d4ed8 / #1e40af 与白字。
- 标题中文无衬线 semibold 18/20px，摘要同字体 14/16px，时间 12px 等宽；4px 间距基础、文章之间细分隔、悬停整行轻微提亮。
- Signature：六分区的真实来源文章直接组成阅读流，来源标签可继续浏览平台；使用来源名称而非无数据支撑的主题标签和来源计数。
- 范围：现有首页页头、分区锚点、文章组；已有搜索弹窗只增强标记。手机、桌面、键盘、深浅主题均覆盖。

## Verification

- Web 69 项测试通过，覆盖六分区摘要和来源、空状态、部分失败、缺失字段及新闻详情跳转；生产构建通过，保持 39 个路由。
- 真实云端内容在本地首页验证；桌面与 390×844 手机、明暗主题检查通过。手机分区锚点可用，新闻标题与摘要自然换行，未出现页面横向溢出。
- 搜索真实词“模型”在标题与摘要中显示深蓝底白字；浏览器 computed style 验证暗色背景 rgb(30,64,175)、文字 rgb(255,255,255)。
- 根据 WCAG sRGB 相对亮度计算，浅色标记文字对比度 6.70:1，暗色 8.72:1，均超过普通文字 4.5:1。

## Review

- Standards：复用现有 UI 技术栈、来源注册与查询，不改生产 API、数据库、权限或 Cron；SiteShell 只增加可选主内容布局，其他页面保留默认间距。
- Spec：删除巨幅页头与每个平台的稀疏面板，变为六分区的文章列表；真实摘要、时间、来源标签及明暗高亮均覆盖。
- Visual：手机首稿分区导航换行占用额外空间，已改为可横向滑动单行；来源链接保持手机 44px 点击高度；不使用假标签、来源数量或跨平台排名。
- 无阻塞问题，无已接受的范围外后续，不创建空 roadmap。

## Risks

上游部分文章没有摘要或时间；按真实数据省略。首页是各来源首条内容的分区预览，不代表全量历史或跨平台热度排名。

# 分区统一文章列表

## Background

用户要求移除平台分组标题、描述、数量和查看全部，直接按时间阅读文章。

## Scope

六个分区概览复用 HotList，保留平台导航，每条显示平台图标、名称、时间和简介。

## Out of scope

不修改首页、单平台页、原文中转或新闻详情，不增加数据源、请求原文、修改数据库或部署。

## Acceptance criteria

- 分区展示所有已加载文章，不再每个平台限制三条；跨平台按发布时间降序，缺失时间最后，连续编号。
- 每项平台标识可进入对应来源；简介最多 240 字符、三行。
- RSS 解析现有 description 优先、content:encoded 纯文本兜底；两者都没有则不虚构简介。
- 有部分来源错误时保留可用文章并提示；全空展示空状态。

## Feasibility

可行。现有采集器已将正文兜底写入 summary，HotList 已支持平台与简介，复用发布时间比较器即可，无额外查询或迁移。

## Implementation

继续 feat/section-rss-feeds，保留原有 next-env.d.ts 修改。复用 home-list-navigation 的已确认样式。
使用 frontend-design、dammyjay93/interface-design 和 ibelick/baseline-ui 指导此次增量。
读者任务是浏览最新动态；标题为视觉焦点，简介与平台时间为次级信息。保留冷蓝交互色、中性背景、细分隔线、现有字体和 4px 间距体系，20px 行内上下留白，不新增卡片或动画。桌面/移动端共用现有 HotList 换行与主题样式。

## Risks

# 分区 RSS 订阅入口

## Background
六个分区已有 RSS 输出，但页面没有订阅入口。用户确认增加分区按钮和配置流程弹窗，并授权将已有 next-env.d.ts 修改一起提交。

## Scope
在六个分区总览及平台列表的共用标题区加入 RSS 订阅按钮。弹窗显示分区完整地址、复制操作、阅读器配置三步骤及复制结果。

## Out of scope
自定义来源管理、单平台 Feed、新页面、采集和部署变更。

## Acceptance criteria
六分区地址对应现有 /feeds/{section}.xml；复制成功有反馈，失败可手动选择地址；弹窗支持键盘关闭、焦点恢复、手机和桌面布局。

## Feasibility
可行。复用现有 SectionLayout、ActionButton、React Aria 1.17.0 Dialog 与 Tailwind 4.3.3 语义样式，无新依赖。仅在用户打开弹窗时读取浏览器 origin，避免 SSR 访问 window。剪贴板权限失败保留可选择的地址。

## Implementation
用户已确认按钮与弹窗流程，沿用现有搜索弹窗的视觉方向：语义背景、边框、主色焦点、小标题和紧凑说明。手机弹窗保持四周留白并允许内部滚动。UI Skills MCP 当前没有可调用工具或本地配置，按技能允许的回退复用现有设计系统，不声称完成 UI Skills 评审。

## Verification
- Web 全量测试：35 个文件、116 项通过；类型检查通过。
- 修改的两个组件通过 Biome 检查和格式化。
- 初次生产构建因现有 SITE_URL 缺失失败；临时设置 SITE_URL=http://localhost:3000 后构建通过，55/55 页面生成。未修改环境文件。
- 浏览器实测六分区弹窗地址分别为 /feeds/ai.xml、technology.xml、news.xml、social.xml、finance.xml、games.xml。切换分区后地址正确更新。
- AI 分区复制成功提示、重新打开清除提示、Esc 关闭及焦点返回按钮通过；六分区关闭按钮均可用。
- 1280×720 桌面与 390×844 手机浅色弹窗、手机深色弹窗视觉检查通过，说明自然换行，地址输入框不撑宽弹窗。
- 自动复制失败分支经代码检查，保留只读可选择输入框；未在浏览器强制触发权限拒绝。
- 最终标准与需求评审没有阻断项；无需新增后续路线图。构建自动重写 next-env.d.ts 后，按用户授权保留原来的 dev 类型路径并纳入提交。

## Risks
非安全上下文或浏览器权限可能阻止自动复制，弹窗提供手动复制提示。Feed 可用性仍取决于现有服务。

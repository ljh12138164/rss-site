# 阅读效率与采集管理

## Background

用户授权实现个人关注页、搜索筛选、长文阅读增强、后台采集看板及精细 RSS，并要求 roadmap 逐一实现验证。路线图：[reading-productivity](../roadmaps/reading-productivity.md)。分支 `feat/reading-productivity` 基于最新 `origin/master`（`8cca2f9`），起始工作区干净。

## Scope

1. `/following` 个人文章关注页：平台关注/隐藏、只看未读、本地持久化。
2. 现有搜索弹窗增加分区、文章平台和最近一天/一周筛选。
3. 现有文章阅读器增加目录、阅读时间、保存位置和继续阅读。
4. `/admin` 增加管理员采集看板；只读，不添加手动采集或源配置。
5. 现有 RSS 弹窗增加单平台及多平台组合；保留六个分区 RSS 地址。

## Out of scope

用户登录/云同步、正文搜索、AI 摘要及推送、添加/启用新源或 Cron、生产 Web 发布。非文章型开源/Skills 排行继续使用其现有页面，不混入个人文章列表。未读沿用现有定义：未出现在当前浏览器最近 100 条阅读足迹中的文章。

## Acceptance criteria

每个阶段满足 roadmap 完成信号；所有新增控件支持键盘、可见焦点及手机布局。空、加载、权限拒绝和失败状态可恢复。个人偏好/阅读进度不在服务器保存。后台不返回 error_message；匿名及普通用户无法读取管理统计。RSS 不接受任意上游 URL。既有分页、翻译、文章管理及 RSS 契约保持兼容。

## Feasibility

可行，无需新运行时依赖。复用 Next 16.3.4、React 19.2.8、Hono 4.13.5、Supabase JS 2.115.0、React Query 5.102.8、React Aria 1.17.0、Tailwind 4.3.3。已阅读安装版本的 Next page/route 文档，以及 Supabase Functions/RPC 官方文档。采集看板需要一项可加性迁移：列级只读权限、管理员 RLS、security-invoker 统计函数；使用当前 JWT 调用，不使用 service key。

技术边界：来源筛选应在数据库执行，未读使用客户端本地历史且不能因过滤出空页停止分页；关键词/来源/时间均参与搜索缓存键；目录在实际渲染正文中生成以兼容双语和视频组件；位置恢复由用户点击，避免浏览器返回时争抢滚动；连续失败按保留的运行记录计算，正文覆盖率明确统计口径。

## Implementation

用户已确认上轮提出的五项产品范围及无需登录的本地存储方案。复用既有阅读列表、文章后台、搜索和 RSS 的 UI 决策，不重复请求确认。唯一新增整页 `/following`；其他均在现有表面嵌入。普通读者扫读关注文章，管理员查看源健康。继续使用报刊式文章列表、现有衬线标题和灰白/青色语义 tokens，4px 间距基准，分隔线组织来源和指标，内容为视觉焦点，无新增装饰动效。桌面/手机及明暗主题在范围内。

已应用 develop-with-pr、Ponytail、frontend-design、Supabase 指导，并读取 UI Skills `ibelick/baseline-ui`、`dammyjay93/interface-design`。复用 SiteShell、HotList、ActionButton 和 React Aria 弹窗；原生表单用于简单筛选。

## Verification

### 阶段验收

1. **个人关注页**：偏好解析、隐藏优先、保存失败及来源/缓存键测试通过；浏览器验证关注、隐藏、刷新保留、跨标签同步。打开文章后，“只看未读”立即排除该文；两来源 40 篇快照通过游标续载，排除三篇已读后显示 37 篇并正确结束分页。首次无关注显示配置入口，API 失败可重试。个人页设置 noindex。
2. **搜索筛选**：参数拒绝、分区/来源组合、最近一天/一周及固定截止时间测试通过；浏览器搜索 `model`、AI/OpenAI/最近一周返回 3 条匹配结果。切换条件重置页码，时间窗口在一次打开期间固定，缓存键包含全部条件；原标题/摘要匹配和摘录保持兼容。
3. **长文阅读**：时间估算、损坏/被禁用存储、进度上限 100 篇测试通过。公开文章 `The eternal complement` 显示 7 节、预计 16 分钟，目录定位与标题顶部距离约 160px；刷新后显示 42% 续读并能恢复。使用临时本地页面验证原文/译文目录各 3 节、双语只生成 3 个唯一锚点、无正文无目录；临时页面已删除。未调用真实模型执行新的翻译。
4. **采集看板**：API 管理员/非管理员/RPC 失败测试、状态计算测试通过。版本化迁移 `20261002053650_ingestion_health.sql` 已应用到关联云端数据库；真实查询得到 40 个已采集来源、最近样本 2,984 篇，其中 2,872 篇有正文，最新成功时间 `2026-10-02 04:25:00.635 UTC`，数量关系合理。云端事务测试验证成功后连续失败计数、运行中不计入失败、管理员列权限、普通用户及匿名拒绝、伪造 user_metadata 无效、error_message 不可读；测试全部回滚。安全检查返回零项。浏览器以本地 Auth 替身验证看板、分区筛选、刷新和退出登录；真实管理员登录仍需发布后验收。
5. **精细 RSS**：旧分区地址、单平台、跨分区组合、排序去重、无效/排行来源、XML 转义、GUID、缓存及失败重试测试通过。本地完整路由验证 OpenAI 10 条、OpenAI+掘金 20 条且分类仅含所选平台；旧 AI 分区地址仍为 200，非法来源为 400/no-store。浏览器验证单平台地址、跨分区选中保留、空选择禁用复制及复制成功。

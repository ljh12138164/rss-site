# 虎扑主帖与精选回复

## Background

虎扑 Feed 抽样 30 条，11 条纯图、3 条纯视频、6 条无正文。方向沿用知乎的主帖与精选回复布局。

## Scope

RSSHub 补齐主帖图片与视频，从公开页面选择最多 3 条不重复的亮评或普通回复。站内沿用现有文章页与移动端布局，展示媒体、回复标题、作者与亮点数。没有站内内容时提示查看原文。

## Out of scope

全量评论、楼中楼和历史回填。

## Acceptance criteria

纯图和纯视频帖子可在站内阅读；每帖最多 3 条公开回复，亮评在前；缺失评论时保留主帖，旧 Feed 的虎扑图片标记可继续展示。未受信任的媒体域名不会进入阅读页。

## Feasibility

真实 Feed 的 30 个帖子中，29 个返回有效主帖，25 个有首批回复，23 个提供亮评。回复数据已经随移动原帖下发，无需额外请求或登录。正文和回复继续沿现有 HTML 采集路径入库。

## Implementation

自建 RSSHub 从主帖 HTML 规范化媒体，用既有详情请求中的公开回复数据渲染精选回复。站内为虎扑文章开放受限媒体白名单，并把有效纯媒体当作正文。

## Verification

- 本地完整 RSSHub 服务请求真实虎扑数据，RSS limit=100 返回 49 条、limit=30 返回 30 条、Atom limit=5 返回 5 条，均为 HTTP 200 且链接唯一。49 条中 29 条含图、15 条含视频、47 条带回复，每帖最多 3 条。
- 站内三包类型检查、14 项定向测试及生产构建通过。
- RSSHub 锁定版本的 etag 从公共镜像安装后，项目级类型检查与完整服务运行通过。改动文件的严格 Oxlint 检查通过。命名空间复杂度检查仍报告原有 utils.ts 回调（CCN 14）。
- 站点 [PR #136](https://github.com/ljh12138164/rss-site/pull/136) 目标 master。精选回复生产验收等待自建 RSSHub 发布与后续采集。
## Risks

虎扑可以删除或限制原帖。RSSHub 发布及下一轮采集后才会出现精选回复。播放器依赖虎扑媒体源。

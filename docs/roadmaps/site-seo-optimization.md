# 全站 SEO 后续路线图

基线审计时间：2026-09-20。当前综合基线为 59/100；它描述部署前的线上站点，不代表本次代码改动上线后的分数。

## 现在

1. 部署本次元数据、结构化数据、sitemap、`llms.txt` 与安全响应头改动。
   - 依赖：正常发布当前 Web 应用。
   - 完成信号：首页、栏目、文章、sitemap 和 `llms.txt` 的生产响应与构建产物一致。
2. 为文章持久化内容质量和索引资格。
   - 证据：线上部分文章正文过短或被上游截断，但仍进入 sitemap 并可索引。
   - 建议字段：抓取完整性、正文长度、解析状态、质量判定和判定时间。
   - 完成信号：低质量文章输出 `noindex` 且不进入 sitemap；抽样检查不会误伤正文完整的文章。
3. 发布后重跑移动端与桌面端审计。
   - 证据：线上首页仍是旧版本，当前工作区已有未发布的 digest 改版。
   - 完成信号：重新记录 Lighthouse、HTML 元数据、JSON-LD、sitemap 延迟和移动端截图。

## 接下来

1. 补齐运营主体、编辑方法、来源选择、纠错方式、翻译说明和联系方式。
   - 完成信号：说明页给出可验证的信息，文章页能链接到方法与纠错入口。
2. 制作 1200×630 的品牌社交分享图，并为有可靠图片的文章提供独立图片。
   - 完成信号：Open Graph 与 Twitter 卡片通过分享调试器，图片不裁掉标题或品牌标识。
3. 增加基于主题和来源的相关文章链接。
   - 完成信号：文章页出现有意义的站内下一步，且链接目标可索引、与正文相关。
4. 在部署后性能数据上评估高基数列表的预取策略。
   - 完成信号：移动端 LCP/TBT 稳定改善，导航体验无回退。
5. 明确 AI 抓取、引用与训练用途政策。
   - 完成信号：`robots.txt`、`llms.txt` 和公开政策页表述一致。

## 后续

1. 为 CSP 设计 nonce 和允许来源，覆盖 Next.js、Google Analytics、Umami 与 AdSense。
2. 接入 Search Console、GA4 与 CrUX，按模板、来源和查询监测索引覆盖、点击率及真实 CWV。
3. 产出每日跨来源原创摘要，公开去重、排序和选题方法，减少聚合页的同质化。

## 复核指标

- 有效索引页与 sitemap URL 数量一致，薄内容不进入索引。
- 文章富结果测试无错误，来源与修改时间准确。
- 主要模板的移动端 LCP、INP、CLS 使用真实用户数据持续监测。
- 品牌查询、非品牌查询、自然点击和收录文章数有可追踪的月度基线。
